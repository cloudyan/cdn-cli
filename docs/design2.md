# CDN-CLI2 模块设计文档

## 1. 概述

CDN-CLI2 是一个用于自动化将静态资源上传到各种 CDN 服务的命令行工具。该工具支持多种云存储服务提供商，包括阿里云 OSS、腾讯云 COS 和七牛云等。

## 2. 核心模块架构

CDN-CLI2 采用模块化设计，主要由以下几个核心模块组成：

### 2.1 配置管理模块 (config.js)

负责管理 CDN 上传相关的配置信息，包括：

- 从环境变量中读取 CDN 服务的配置信息
- 提供默认配置，如缓存控制策略、重试次数
- 支持不同 CDN 服务商的配置（阿里云、七牛云、腾讯云）

### 2.2 文件处理模块 (files.js)

负责文件遍历和处理：

- 使用 glob 和 dir-glob 处理文件路径
- 遍历指定目录收集需要上传的文件
- 过滤不需要上传的文件（基于配置的排除规则）
- 构建本地文件路径与目标 CDN 路径的映射关系

### 2.3 上传模块 (upload/\*)

采用适配器模式实现不同 CDN 服务的上传功能：

- upload/index.js：统一上传接口和逻辑流程
- upload/aliyun.js：阿里云 OSS 适配器
- upload/qiniu.js：七牛云适配器
- upload/tencent.js：腾讯云适配器

上传模块实现的主要功能：

- 文件存在性检查
- 根据文件类型设置不同的缓存策略
- 上传失败重试机制
- 上传进度跟踪与日志记录

### 2.4 部署模块 (deploy.js)

负责执行部署流程：

- 安全性检查，避免上传敏感文件（如 package.json）
- 处理部署参数，如源目录、目标路径
- 支持预览模式，可以在上传前查看将要上传的文件列表
- 协调文件处理和上传模块完成资源部署

### 2.5 工具模块 (utils.js)

提供各种辅助功能：

- 文件/目录检测工具
- 文件复制功能
- 文件存在性检查

### 2.6 初始化模块 (init.js)

负责配置文件初始化与管理：

- 创建默认配置文件
- 清除现有配置
- 获取本地配置信息

### 2.7 日志模块 (logger.js)

提供统一的日志输出接口：

- 成功、失败、信息等不同类型日志的标准化输出
- 支持彩色日志输出

### 2.8 更新检查模块 (update.js)

负责检查 CDN-CLI2 工具的版本更新：

- 检测是否有新版本可用
- 提醒用户更新工具

## 3. 设计模式

### 3.1 适配器模式

通过适配器模式实现对不同 CDN 服务商 API 的统一调用接口，使得系统能够轻松支持多种 CDN 服务商。

### 3.2 策略模式

针对不同类型文件（如 HTML vs 静态资源）采用不同的缓存策略，通过策略模式实现缓存控制逻辑的灵活配置。

### 3.3 命令模式

通过命令行接口实现各种操作，如部署、初始化、更新检查等功能，具有良好的可扩展性。

## 4. 数据流

1. 用户通过命令行接口触发部署操作
2. 系统读取配置信息（环境变量或配置文件）
3. 扫描并收集需要上传的文件
4. 执行安全检查，确保不上传敏感文件
5. 按照配置的 CDN 服务商执行上传
6. 检查文件是否已存在于 CDN
7. 根据文件类型设置适当的 HTTP 头信息
8. 执行上传并处理可能的错误与重试
9. 输出上传结果日志

## 5. 扩展点

该模块设计包含多个扩展点：

1. **新增 CDN 服务商支持**：只需添加新的适配器实现
2. **自定义缓存策略**：通过配置修改不同文件类型的缓存策略
3. **文件过滤规则**：自定义排除规则决定哪些文件不上传
4. **错误处理策略**：可配置重试次数和错误忽略选项

## 6. 总结

CDN-CLI2 采用模块化设计，具有良好的可扩展性和可维护性。通过适配器模式支持多种 CDN 服务商，使用策略模式处理不同文件类型的缓存控制，为静态资源部署到 CDN 提供了高效且灵活的解决方案。模块间职责明确，代码结构清晰，便于进一步扩展和优化。
